How It Works

To render crisp, legible typography on limited LED arrays, each character resides within a bounding box, accompanied by 1-pixel spacer padding. This prevents bleeding between consecutive letters.

Spacing Guides Color Key:

  • Active Character Box
  • Padding Pixels (1px Right/Bottom)
  • Remaining margin pixels (unused layout pixels)
